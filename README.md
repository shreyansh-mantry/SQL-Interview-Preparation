# SQL-Interview-Preparation


🧩 Question Format explains the two files in every folder (Question and Solution) and what each section inside them contains. It also explains the 🟢 🟡 🔴 difficulty levels and how to use the copy button on code blocks.
▶️ How to Run the Code Online (DB Fiddle) is a beginner’s guide in four steps:
Open DB Fiddle and choose MySQL 8.0, with a warning not to pick 5.x.
Paste the Create Table and Insert blocks into the left Schema SQL panel.
Write your query in the right Query SQL panel.
Click Run and compare the result with the expected output.
It also includes a worked example using Question 6, plus tips: every Run starts fresh, change the data to test edge cases, common errors, and the warning that a Save link is visible to anyone who has it.
